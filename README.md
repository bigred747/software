# software

WordPress plugins for [luxetrendsetters.com](https://luxetrendsetters.com/).

## Luxe Product Integrity Repair 1.0.0

Companion to Product Scout 5.6.4. Repairs taxonomy/brand conflicts that cap honest product scores at 94. Does not write fake 100s.

- Zip: `dist/Luxe-Product-Integrity-Repair-v1.0.0.zip`
- Install as a **new** plugin → Tools → Luxe Product Integrity → **Repair ALL catalog conflicts** → Product Scout → **Run Full Catalog Audit**
