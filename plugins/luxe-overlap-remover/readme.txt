Deactivates and deletes 18 named overlap plugins. Each safety lock and each folder has its own green, yellow, or red signal.

== Description ==

Open Tools → Overlap Remover. Green on a plugin row means that folder is already gone. Yellow means it is still installed. Delete runs only after the Snapshot backup box is checked.

The remover does not hook the public site. It cannot match WooCommerce, WZone, Rank Math, LiteSpeed, Wordfence, Amazon Bridge, Product Scout, Ultimate Authority, Theme Guard, or the homepage keeper.

== Installation ==

Upload the zip from Plugins → Add Plugin. Activate it. Open Tools → Overlap Remover. Scan, confirm the backup, then delete.
