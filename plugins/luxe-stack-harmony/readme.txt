== Description ==

Luxe Stack Harmony makes the live plugin stack work together.

* One Blog Master repair engine (Command Center). Cancels Green Board / extra copies
* PARK: Hostinger AI, Bad Content Eraser, Master Plugin Orchestrator — deactivate only
* KEEP never deactivated (Command Center, Finish, Rank Math, Woo, Bridge, Mirror Master, Theme Guard, Mission Control, …)
* Finish remains the public HTML last pass — Harmony adds zero frontend JS/CSS
* 15-minute 24/7 learning with a green-signal board

Never writes post_content. Never publishes. Never deletes. Never rewrites Amazon URLs.

== Installation ==

1. Upload `luxe-stack-harmony.zip` in Plugins → Add Plugin → Upload Plugin.
2. Install into a **new** folder named `luxe-stack-harmony`. Do not replace Command Center, Finish, Luxe SEO, Theme Guard, Mission Control, Stay Repair, Reader-Love, Hard Rescue, Product Scout, Amazon Bridge, or Mirror Master.
3. Activate. Open **Luxe Harmony**. Click **Run harmony learning now**.
