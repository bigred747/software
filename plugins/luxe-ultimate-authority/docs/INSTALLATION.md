# Luxe Ultimate Authority & Revenue Engine 1.0.0

Upload `dist/Luxe-Ultimate-Authority-v1.0.0.zip` in Plugins → Add Plugin → Upload Plugin.

Activate it, then open Tools → Ultimate Authority.

1. Read the process signals. Green means that check is clear. Yellow means a guide or archive still needs you.
2. Click **Scan next 10 guides**. The scan stores flags. It does not publish, change status, or edit the article.
3. Open a high-opportunity guide. Write the verdict, pros, cons, buyers, scores, comparison, and FAQ yourself. Approve a block only after the fields are real.
4. Approve noindex only for weight archives and product tags. Leave shopping categories indexed.
5. Take a Snapshot Pro backup before using **Deactivate overlapping plugins**.

Rank Math, LiteSpeed, Wordfence, WooCommerce, WZone, Link Whisper, Amazon Bridge, and Product Scout stay active. Homepage plugins are not in the retire list.
