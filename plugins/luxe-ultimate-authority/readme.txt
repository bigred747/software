One signal board for guide quality, revenue gaps, and index recommendations. Approval is required before any block is public.

== Description ==

Replaces the overlapping Luxe scanners with one Tools screen. Rank Math, LiteSpeed, Wordfence, WooCommerce, WZone, Link Whisper, Amazon Bridge, and Product Scout stay in place.

Each process has a green, yellow, or red signal:

* Safety locks for publish, post status, Amazon URLs, and invented experience
* Thin content, duplicate phrases, article score, and internal-link gaps
* Verdict, pros and cons, buyer types, scorecard, comparison, and FAQ drafts
* Affiliate link shape, tag check, missing button, and content-gap opportunity
* Rank Math title and description checks, H1 count, schema owner, cannibalization
* Weight archives, product tags, empty archives, and thin categories
* LiteSpeed, image dimensions, cache headers, and a lock that blocks a second optimizer
* Overlapping plugin report

Nothing is published automatically. Post status is never changed. Article HTML is never replaced. Amazon URLs are never rewritten.

== Installation ==

1. Upload the zip in Plugins → Add Plugin.
2. Activate Luxe Ultimate Authority & Revenue Engine 1.0.0.
3. Open Tools → Ultimate Authority.
4. Scan the next 10 guides, then edit a guide and approve only the blocks you wrote.
