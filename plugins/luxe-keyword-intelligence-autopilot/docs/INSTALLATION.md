# Luxe Keyword Intelligence Autopilot 1.4.0

Upload `luxe-keyword-intelligence-autopilot.zip`. Do not unzip it.

On an iPhone, download the zip in Safari to Files. In the site admin in the browser: Plugins → Add New → Upload Plugin → choose that zip → Install Now → Activate.

Open **Keyword Autopilot** and click **Repair attention items**. Each click repairs up to 48 items when the server load is around 32. The engine then continues every 5 minutes.

The WordPress status of every post stays as it is. Article bodies are not rewritten.
