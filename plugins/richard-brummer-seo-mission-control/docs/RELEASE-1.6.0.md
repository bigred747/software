## Release purpose

Version 1.6.0 adds an original Social Growth Lab for building a high-volume but review-controlled distribution queue from the site owner's own content, experience, research, measurements, and authorized media.

The release does not reproduce the creator, reel, screenshots, prompts, captions, visual design, audience data, or proprietary process that inspired the general business goal. The implementation, wording, templates, scoring, data model, admin interface, and documentation are independently written for this plugin.

## New process

The Social Growth tab can:

- Create a publish-ready local campaign package from a specific topic, audience, firsthand insight, goal, format, angle, duration, and same-site destination.
- Generate five hook choices, a timed script, an original shot list, caption, tracked UTM URL, restrained hashtag set, and platform checklist.
- Build up to thirty idea-only records from ten published pages. Each page receives three angles: three checks, a mistake to avoid, and who should skip it.
- Export a campaign as plain text or the queue as CSV.
- Store manually entered platform performance evidence.
- Learn the best-performing angle, duration, and format during bounded hourly cycles.

## Copyright and originality controls

A publish-ready package requires an administrator attestation that every word, image, clip, voice, logo, music track, screenshot, product shot, and factual claim is owned, licensed, public domain, or otherwise authorized.

The plugin also:

- Does not accept an external destination URL in the package builder.
- Does not import external social text or media.
- Does not copy the body of the selected WordPress source page; it uses only the title and destination URL automatically.
- Compares the new topic, audience, firsthand input, and angle with prior local campaigns using four-word-shingle Jaccard similarity.
- Blocks campaign creation at 75% local similarity.
- Marks thirty-day queue entries as idea-only until firsthand input and the rights attestation are completed.

No local checker can prove worldwide copyright clearance. Final responsibility for facts, trademarks, quotations, product images, music, videos, recordings, logos, and permissions remains with the publisher.

## Platform boundaries

The checklist covers Trial Reels, caption translation, cross-posting, product tags, tracked links, disclosures, and AI labels. Those are platform-controlled features. Version 1.6.0 does not store Meta access tokens, scrape social profiles, buy engagement, impersonate users, or auto-publish.

## Traffic and ranking boundary

The plugin is designed to improve the quality and measurability of a distribution workflow. It does not promise a specific number of views, followers, clicks, conversions, or Google rankings. Performance learning uses only evidence entered by the administrator.

## Compatibility

The release preserves all 1.5.0 ownership boundaries. Mission Control remains the evidence and orchestration layer. It does not take ownership from the blog builder, link manager, cache plugin, schema plugin, security plugin, WooCommerce, or social platforms.
