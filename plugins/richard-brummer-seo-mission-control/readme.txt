== Description ==

Version 1.9.0 is a complete Mission Control package:

* Amazon marketplace allowlist and lookalike-domain rejection
* Verified score excludes MANUAL and INFO
* Compatibility catalog of 38 plugins
* JSON-LD strict parsing with SHA-256 evidence
* Optional rendered Amazon identification and invalid JSON-LD quarantine
* Stay Repair for LiteSpeed Guest Mode 1-second sessions, 404s, leaked shortcodes
* Search Console credentials via wp-config.php only (never stored in options)
* Does not auto-publish, rewrite stored posts, or trap the back button

== Installation ==

1. Backup.
2. Plugins → Add Plugin → Upload Plugin.
3. Upload Richard-Brummer-SEO-Mission-Control-v1.9.0.zip
4. If WordPress asks to replace 1.2.0, choose replace.
5. If 1.8.1 is already live, keep 1.8.1 and use this only if you intend to replace it.
6. Activate, purge LiteSpeed, turn Guest Mode OFF, run full audit.
