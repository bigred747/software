# Install Luxe Download Scout 1.0.0

Upload the zip from Windows into WordPress. Do not unzip it on the PC.

1. Confirm **Luxe Affiliate Product Scout 5.6.8** is installed and active. Download Scout uses that supported-brand list.
2. Plugins → Add Plugin → Upload Plugin → choose `luxe-download-scout.zip` → Install Now → Activate.
3. Open **Luxe Download Scout**.
4. Paste the WZone product list, including each price and the “Add to import list” or “Already Imported” line.
5. Click **Show products to download**.

The screen reads the WooCommerce catalog. It does not import, publish, delete, or rewrite affiliate URLs.

On the WZone card, confirm an ASIN and a primary image before you add a recommended row. Unknown-brand, renewed, used, refurbished, and duplicate models stay off the list.
