# Install Luxe Download Scout 1.1.0

Upload the zip from Windows into WordPress. Do not unzip it on the PC.

1. Confirm **Luxe Affiliate Product Scout 5.6.8** is installed and active. Download Scout uses that supported-brand list.
2. Plugins → Add Plugin → Upload Plugin → choose `luxe-download-scout.zip` → Install Now → Replace current with uploaded → Activate.
3. Open **Luxe Download Scout**.
4. Paste the WZone product list, including each price and the “Add to import list” or “Already Imported” line.
5. Click **Add the very best to Products**.

Each 100-score row becomes an unpublished draft in the matching category, such as Drones. A 95-score row is not added. Open Products → Drafts to see them. Add the ASIN and primary image on the draft before you publish it.
