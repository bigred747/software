# Safety

Luxe Download Scout 1.0.0 will not:

- import a product
- publish a draft, pending, or private item
- change publication status
- delete products, posts, or pages
- rewrite Amazon or affiliate URLs
- invent ratings, seller, warranty, or unknown brands
- call external scoring or AI APIs
- run on a public page view

It may:

- read WooCommerce product names when an administrator opens the screen
- score a pasted WZone list against the Product Scout brand list
- remember the last paste in an admin option

Product Scout still owns catalog repair and 24/7 scoring. Keyword Intelligence still owns Rank Math keyword work. Mission Control still owns evidence auditing.
