== Description ==

**Luxe Blog Master 2.8.1** is the identity plugin Mission Control 1.8.2 looks for. It is the approval companion and hard no-publish lock. The writer remains Luxe Blog Master Command Center. This plugin never publishes, never deletes, and never rewrites Amazon URLs.

== Installation ==

1. Upload `luxe-blog-master.zip` from Windows 11.
2. If WordPress offers **Replace current with uploaded**, that is the 2.9.6 stub. Replace, then Activate.
3. Confirm **Plugins** shows **Luxe Blog Master Version 2.8.1** as Active.
4. Leave **Luxe Blog Master Command Center** active. Do not deactivate it.
5. Open Richard Brummer SEO and run the complete dashboard refresh.
