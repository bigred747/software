== Description ==

**Do not install this zip.** Live Command Center already lists Luxe Blog Master at Version **2.9.6**. WordPress will correctly warn that 2.8.1 is an older plugin. Replacing 2.9.6 with this file can wipe Command Center.

The writer remains Luxe Blog Master Command Center. Optional upgrade is Command Center **2.9.8**, which is no longer a second listed Luxe Blog Master plugin. This file never publishes, never deletes, and never rewrites Amazon URLs.

== Installation ==

1. Do **not** upload `luxe-blog-master.zip`.
2. If WordPress already shows “You are uploading an older version”, **cancel**.
3. Keep live **2.9.6**. Optional Command Center upgrade is **2.9.8**.
