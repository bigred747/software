== Description ==

Luxe Operator Dashboard is an original admin-only plugin for luxetrendsetters.com.

* Removes YITH news, YITH changelogs, WordPress news, Quick Draft, empty WooCommerce reviews, and the empty Site Health widget from Dashboard.
* Hides repeating plugin nags on the Dashboard screen, with a one-click show toggle.
* Hides Rank Math’s “Latest Blog Posts” marketing block inside Overview. 404 / redirection counts stay.
* Hides Site Kit Reader Revenue Manager, Google Ads, and AdSense connect upsells. This site is Amazon affiliate, not AdSense.
* Adds one operator card that translates the scary numbers into next actions.
* Does not auto-write, auto-publish, hook frontend content, or run content cron.
* Does not deactivate Luxe Hard Rescue Admin Cleaner.

== Installation ==

1. Backup the site.
2. Plugins → Add Plugin → Upload Plugin.
3. Upload `Luxe-Operator-Dashboard-v1.1.1.zip` and activate.
4. Open Dashboard. The operator card is at the top.
5. Optional: Tools → Luxe Operator.
