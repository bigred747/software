== Description ==

Luxe Public Finish is the storefront last pass for luxetrendsetters.com.

* Restores clipped document / Open Graph titles (`| Pr`, `Review & Buyer Che`)
* Unique-ifies duplicate product listing labels with SKU or #ID (HTML only)
* Keeps one official Amazon Associate identification
* Keeps one Organization JSON-LD graph
* 15-minute 24/7 learning with a green-signal board
* Adds **zero** frontend JavaScript or CSS

Never writes post_content or post_title. Never publishes. Never deletes. Never rewrites Amazon URLs. Never copies Instagram video.

== Installation ==

1. Upload `luxe-public-finish.zip` in Plugins → Add Plugin → Upload Plugin.
2. Install into a **new** folder. Do not replace Luxe SEO, Theme Guard, Mission Control, Stay Repair, Product Scout, Keyword Autopilot, Reader-Love, or Hard Rescue.
3. Activate. Open **Luxe Finish**. Click **Run finish learning now**.
