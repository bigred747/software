# Luxe Score Repair 1.2.1

Safe public-output plugin for https://luxetrendsetters.com/. Search focus points Google at products and published buyer guides instead of thin product-tag pages.

This cannot invent Search Console clicks. Direct 1-second Analytics sessions are not search traffic. The WordPress Tools screen will not show Google numbers going up.

## Install

1. Download [luxe-score-repair.zip](https://github.com/bigred747/software/raw/refs/heads/cursor/score-repair-search-focus-e8f3/luxe-score-repair.zip).
2. Plugins → Add Plugin → Upload Plugin. Upload **over** 1.2.0 (same folder `luxe-score-repair`).
3. Confirm **Plugins** shows **Version 1.2.1**.
4. Open **Luxe Score Repair** in the **left admin menu** (not only Tools).
5. Click **Run process learning now**.

Do **not** upload this zip over Mission Control, Stay Repair, or Product Scout.

## What 1.2.1 does

- Same search-focus repairs as 1.2.0
- Puts the board in the left menu so it is not lost under Tools notices
- Heals `robots.txt` after a zip replace (WordPress does not run activate on replace)
- Drops the leftover 19/22 signal board from the previous plugin
