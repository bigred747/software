# Luxe Score Repair 1.2.2

Safe public-output plugin for https://luxetrendsetters.com/. Search focus points Google at products and published buyer guides.

16/19 after clicking Run process learning was **not** the site getting worse. The 18/19 run skipped homepage fetches (loopback) and auto-greened those rows. The next run actually fetched the homepage, then used checks that fail on WordPress loopback even when the public site is green.

1.2.2 fixes those false reds. Search focus is unchanged.

## Install

1. Download [luxe-score-repair.zip](https://github.com/bigred747/software/raw/refs/heads/cursor/score-repair-search-focus-e8f3/luxe-score-repair.zip).
2. Upload **over** 1.2.1 (same folder `luxe-score-repair`).
3. Confirm **Version 1.2.2**.
4. Open **Luxe Score Repair** in the left admin menu.
5. Click **Run process learning now**.

Do **not** upload this zip over Mission Control, Stay Repair, or Product Scout.
