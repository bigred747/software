Deactivates unused YITH/store and overlapping Luxe scanner plugins. Does not delete files.

== Installation ==

1. Backup.
2. Upload this ZIP in Plugins → Add Plugin → Upload Plugin.
3. Activate. Matching plugins are deactivated immediately.
4. Also upload Mission Control 1.9.0 if you want the stay-time repairs.
5. Purge LiteSpeed cache. Turn Guest Mode OFF.

== Keep ==

WooCommerce, Rank Math, Site Kit, Wordfence, LiteSpeed, Mission Control, Contact Form 7, Classic Editor, Link Guardian, Amazon Bridge, Site Guardian, Hard Rescue, YITH Wishlist.

== Deactivate ==

YITH points, coupons, add-ons, min/max qty, order status, countdown, swatches, frequently bought, gallery zoom, compare, Nextend Social Login, Jetpack, Yoast, Redirection, Keyword Autopilot, AI Readiness Autopilot, Reader-Love, PayPal Payments, Elementor, Autoptimize, WP-Optimize.
