Deactivates overlapping 24/7 Luxe scanners from the live 43-plugin stack. Does not delete files.

== Installation ==

1. Backup (Snapshot Pro is already active).
2. Upload this ZIP in Plugins → Add Plugin → Upload Plugin.
3. Activate. Matching overlap plugins are deactivated immediately.
4. Open Tools → Luxe Consolidator to confirm the list.
5. Upload Stay Repair 1.9.2 over Stay Repair 1.9.1. Do not replace Mission Control 1.8.2.
6. Purge LiteSpeed cache. Keep Guest Mode and Crawler OFF.
