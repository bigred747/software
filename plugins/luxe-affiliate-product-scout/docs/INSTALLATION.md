# Installation

## Luxe Affiliate Product Scout 5.6.8

24/7 catalog learning. Safe Windows 11 / WordPress zip. **145KB**.

**Upload this file:** [luxe-affiliate-product-scout.zip](https://github.com/bigred747/software/raw/refs/heads/cursor/product-scout-95-100-e8f3/luxe-affiliate-product-scout.zip)

If WordPress showed a critical error before: delete every Product Scout folder under `wp-content/plugins/`, then upload this zip. Do not unzip it on the PC.

1. Plugins → Add Plugin → Upload Plugin → Install Now → Replace current with uploaded → Activate.
2. Confirm version **5.6.8**.
3. Open **Luxe Product Scout**. Confirm **24/7 learning is ON**.
4. Click **Repair ALL Catalog Data + Recalculate**.
5. Click **Run Full Catalog Audit** (or **Run learning snapshot**) so the board shows the full catalog, not a 25-product batch.
6. Leave 24/7 on. WP-Cron repairs one product every 5 minutes and snapshots stored scores hourly. Tiny batches never replace the full-catalog scoreboard.

Never publishes, never deletes, never rewrites Amazon URLs.
