# Installation

## Luxe Affiliate Product Scout 5.7.0

24/7 catalog learning plus copyright-safe Instagram video scanning. Safe Windows 11 / WordPress zip. **145KB**.

**Upload this file:** [luxe-affiliate-product-scout.zip](https://github.com/bigred747/software/raw/refs/heads/cursor/instagram-video-scan-0935/luxe-affiliate-product-scout.zip)

If WordPress showed a critical error before: delete every Product Scout folder under `wp-content/plugins/`, then upload this zip. Do not unzip it on the PC.

1. Plugins → Add Plugin → Upload Plugin → Install Now → Replace current with uploaded → Activate.
2. Confirm version **5.7.0**.
3. Open **Luxe Product Scout**. Confirm **24/7 learning is ON**.
4. Click **Repair ALL Catalog Data + Recalculate**.
5. Click **Run Full Catalog Audit** (or **Run learning snapshot**) so the board shows the full catalog, not a 25-product batch.
6. Paste public Instagram reel URLs. Click **Scan all Instagram videos**.
7. Leave 24/7 on. WP-Cron repairs one product every 5 minutes, snapshots stored scores hourly, and scans one queued Instagram permalink per cycle without downloading video.

## Luxe SEO Score Repair 1.2.0

This is the SEO plugin. WordPress admin menu: **Luxe SEO**.

**Upload this file:** [luxe-score-repair.zip](https://github.com/bigred747/software/raw/refs/heads/cursor/instagram-video-scan-0935/luxe-score-repair.zip)

1. Plugins → Add Plugin → Upload Plugin. Upload over the current `luxe-score-repair` folder.
2. Confirm the plugin list shows **Luxe SEO Score Repair 1.2.0**.
3. Open the left admin menu **Luxe SEO** (not buried under Tools).
4. Click **Run process learning now**. All signals should be green.

Never publishes, never deletes, never rewrites Amazon URLs, never copies Instagram video.
