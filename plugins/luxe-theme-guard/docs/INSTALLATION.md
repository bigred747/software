# Luxe Theme Guard 1.0.0

Automatically updates official Flatsome and shows green signals. WordPress admin menu: **Luxe Theme**.

## Install

1. Download `luxe-theme-guard.zip` (145KB Windows 11 / WordPress zip).
2. Plugins → Add Plugin → Upload Plugin → Install Now → Activate.
3. Open the left menu **Luxe Theme**.
4. Click **Check and update Flatsome now**.

Do **not** upload this zip over Flatsome, Product Scout, Luxe SEO, Mission Control, or Stay Repair.

## License

Flatsome is a paid ThemeForest theme. Guard can only auto-update when **Flatsome → Theme Registration** has your purchase code. It will never download a nulled zip.

## Safety

- Official Flatsome parent only
- Child theme is never replaced
- Plugins are never overwritten
- Never publishes content
- Never rewrites Amazon URLs
