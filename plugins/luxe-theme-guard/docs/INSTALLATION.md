# Luxe Theme Guard 1.2.1

24/7 process learning, Amazon AI, and official Flatsome auto-update. WordPress admin menu: **Luxe Theme** and **Amazon AI**.

## Install

1. Download `luxe-theme-guard.zip` (145KB Windows 11 / WordPress zip).
2. Plugins → Add Plugin → Upload Plugin → Install Now → Activate (replace 1.1.x if asked).
3. Open the left menu **Luxe Theme**.
4. Confirm **24/7 process learning** and **Amazon AI** are On.
5. Click **Check and update Flatsome now** or **Run 1 Amazon AI cycle**.

Do **not** upload this zip over Flatsome, Product Scout, Luxe SEO, Mission Control, or Stay Repair.

## 24/7 learning

| Cycle | What it does |
|---|---|
| Every 5 minutes | Learn **one** theme signal and **one** Amazon catalog item. Never publishes. |
| Every hour | Read-only snapshot. Asks WordPress if an official Flatsome package exists. |
| At most every 12 hours | Apply that official parent package if a license is registered. |
| Shopper page view | Only pings `wp-cron.php` in the background. Never writes theme files or Amazon URLs on the public request. |

## Amazon AI

Local audit of ASIN + `tag=luxetrendse0f-20`. Optional live facts from Amazon **Creators API** (PA-API v5 is retired as of May 2026).

1. Associates Central → Tools → Creators API
2. Create Credential ID + Secret
3. Paste them on the Luxe Theme settings form
4. Leave blank to keep local-only audit

Amazon AI never rewrites affiliate URLs, never invents ratings, and never publishes.

If Hostinger has a real cron job, point it at `wp-cron.php` every 5 minutes.

## License

Flatsome is a paid ThemeForest theme. Guard can only auto-update when **Flatsome → Theme Registration** has your purchase code. It will never download a nulled zip.

## Safety

- Official Flatsome parent only
- Child theme is never replaced
- Plugins are never overwritten
- Never publishes content
- Never rewrites Amazon URLs
- Never invents Amazon ratings
