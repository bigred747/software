YITH Wishlist Compatibility Repair (One-Time)
=============================================

What it does
------------
On activation, this plugin finds
`yith-woocommerce-wishlist/.../class-yith-wcwl-compatibility.php`,
backs it up, and writes the repaired version.

Install (once)
--------------
1. In WordPress admin go to Plugins → Add New → Upload Plugin
2. Upload yith-wcwl-compat-repair.zip
3. Click Install Now, then Activate
4. Confirm the green success notice
5. Deactivate and Delete this repair plugin

Requirements
------------
- YITH WooCommerce Wishlist installed
- WordPress able to write into wp-content/plugins
