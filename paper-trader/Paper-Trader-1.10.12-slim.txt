Paper Trader 1.10.12 — slim Windows zip

File: Paper-Trader-1.10.12-slim.zip (~0.7 MB)

Same desk seal as the full zip (Seat Trail · 1.10.12). Omits the bundled
Windows Python runtime and tests so the download stays small.

How to open on the computer
1. Download Paper-Trader-1.10.12-slim.zip
2. Extract All into Documents (or Downloads)
3. Double-click Start-Paper-Trader.bat (or 1 Allow Paper Trader.bat)

Python
- If you already have Documents\Paper Trader\runtime\python.exe from an older
  full zip, keep that folder — the bats reuse it when present.
- Otherwise install Python 3.11+ from python.org and leave "Add to PATH" on.
  The bats fall back to `python` / `py -3` when runtime\python.exe is missing.

Live stays locked. Paper only.
